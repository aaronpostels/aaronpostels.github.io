## Project Overview

VeinMining is a mod I made for Hytale. Hold a key while mining and it breaks the whole connected ore vein at once, or digs out shapes such as cubes and tunnels. Players change the settings in an in-game menu.

## Tech Stack

- Java
- Hytale Plugin API
- Gradle

## Key Features

- **Vein Mining:** Break connected blocks or ores with one action.
- **Excavation Patterns:** Dig cubes, tunnels, walls and staircases.
- **In-Game Menu:** Configure modes and patterns without editing files.
