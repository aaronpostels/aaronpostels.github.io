## Project Overview

Phase Up is a companion app for the card game Phase 10. Instead of playing the same ten phases every time, it deals out new phase sets from a pool of 1,610 phases and keeps track of everyone's progress at the table.

It is a single static page with no build step, installable as a PWA so it keeps working offline once it has been opened.

## Tech Stack

- JavaScript
- HTML
- CSS
- PWA
- Service Worker

## Key Features

- Ready-made sets: Classic (the original 10 phases), Remix and Expert.
- Random runs of 1 to 30 phases with a chosen difficulty range.
- Card guide that explains every phase type with valid and invalid examples.
- Player list and score counter for the whole table.
- Installable to the home screen and fully usable offline.

## Platform & Device Support

Supported devices: mobile, desktop
