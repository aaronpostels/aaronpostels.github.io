Aaron Postels (also "Ducklin") is a developer and Digital Media student at the University of Bremen, focused on AI and game development with a strong web background: B.Sc. finished with a 1.15, now in the M.Sc. Known for Artisan, a Rust/WebAssembly/WebGPU game engine, a real-time digital twin of a Stewart motion platform built for ProCue, and 36 projects: games, web demos and hardware builds.

  • Artisan: A web-first game engine built on an archetype ECS in Rust, compiled to WebAssembly and rendered with WebGPU, with a written paper and six live demos. Live demo. Rust, WebAssembly, WebGPU, Rayon
  • TileQuest: A physical/digital co-op board game using RFID figures on a custom electronic grid. A 4th-semester university group project. Raspberry Pi, Flask, React, ESP32
  • ProCue Motion Platform: A real-time 3D digital twin of a six-axis Stewart motion platform for driving simulators, built for ProCue alongside their website. Live demo. React, TypeScript, React Three Fiber (R3F), Three.js
  • Island: An interactive 3D portfolio where you sail a ship between islands, featuring custom water shaders and spatial audio. Live demo. React Three Fiber (R3F), Three.js, GLSL (Shaders), Zustand
  • Duckslayer: A 3D trick-based soap-surfing game developed in a group for Global Game Jam 2025. Winner of the Bremen site. Live demo. Godot, GDScript
  • Bachelor Thesis: Robot Goal Celebrations: A workflow from video to autonomous goal celebrations on a humanoid football robot: Blender add-on, reinforcement learning in Isaac Lab, and integration into the B-Human system. Tested on the real Booster K1. Blender (Python add-on), Isaac Lab, Reinforcement Learning (PPO), B-Human
  • FrogYou!: A fast-paced 2D precision platformer featuring a ninja frog navigating mechanical hazards, with directional spore dashes, vine grappling, and online speedrun leaderboards. Live demo. Unity, C#, Google Apps Script, Universal Render Pipeline (URP)
  • Platform Kinematics: A real-time 3D web simulator of a 3-axis Stewart platform, created as part of a collaborative hardware project for an electronic systems course. Live demo. React, Three.js, React Three Fiber (R3F), Drei
  • VeinMining: A Hytale mod that lets players mine whole connected ore veins and dig out patterns in one go. Java, Hytale Plugin API, Gradle
  • Flashdash: A 15-meter interactive LED strip game of 1D ping-pong. A collaborative HfK project with a custom display and spatial audio. ESP32, C++, WS2813B LEDs, 3D Printing
  • Aurora: A modern, visual website editor architected as a monorepo for modularity and scalability. Next.js, TypeScript, Turborepo, pnpm
  • Webbox: A static site generator that creates full websites from a single config file using pre-built templates. Nunjucks, Python, HTML, CSS
  • Phase Up: An installable phone app for the card game Phase 10 that generates fresh phase sets and keeps score, fully offline. Live demo. JavaScript, HTML, CSS, PWA
  • Modernized Rotary Telephone: A vintage rotary telephone retrofitted with modern electronics (Bluetooth, battery, custom ringer) to act as an interactive audio guide. ESP32, C++
  • Unity ML-Agents Parkour: Trained AI agents using machine learning to navigate a parkour. A solo project for a first-semester HfK university course. Unity, C#, ML-Agents (Python, TensorFlow)
  • Toolbox: A web app featuring a suite of polished utilities like a QR Code Generator and JSON Formatter. Live demo. React 19, TypeScript, Tailwind CSS v4, Motion
  • Unstable Diffusion: A university group art project using Stable Diffusion to generate figures from abstract 3D depth maps. Blender, Python, Stable Diffusion, Flux
  • HueTogether: A two-player co-op puzzle game developed as a group project for a university course, which won its project showcase. Unreal Engine 5, Blueprints, C++
  • MI2 3D Integration: A solo university project for Medieninformatik 2, involving modeling, animating, and compositing a 3D model into a live-action video. Blender, Unreal Engine 5
  • Eneida: An interactive portfolio simulating a retro sci-fi desktop with a CLI, window manager, and playable games with online leaderboards. Live demo. Vanilla JavaScript (ES6+), Firebase (Firestore), Canvas API
  • NPC Engine: A local AI platform for creating stable, role-playing NPCs. Features custom LoRA training, advanced prompt engineering, and a bespoke Web UI. Python, PyTorch, FastAPI, Transformers
  • RPG Combat Minigame: A tech demo for a turn-based combat system, prototyped for the TileQuest project, featuring skill-based minigames. Live demo. Vanilla JavaScript, CSS Animations, DOM API
